# Domu
Repositorio usado por el Grupo 12 de DAW para la realización del proyecto.

## Proceso del pensamiento de diseño

### Descripción del tema
El objeto de este proyecto es proporcionar soluciones a la gestión de comunidades de vecinos. 

Domu es una aplicación web responsive (con visualización multiplataforma) que pretende englobar toda la gestión de una comunidad de vecinos. Estas comunidades pueden tener diferentes instalaciones pero, principalmente, la aplicación servirá para gestionar presupuestos, gastos, mantenimiento, votaciones, reuniones, etc. Además de incluir paneles informativos para comunicados, datos de la comunidad y vecinos, reservas de espacios comunitarios (en el caso que los haya), etc.
Para el desarrollo de esta aplicación se localiza el problema principal de la gestión de estas comunidades y se plantean las siguientes soluciones.
